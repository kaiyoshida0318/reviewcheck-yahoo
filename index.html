並び：🔔伝令ちゃん（1枚目用・2枚目用のみ）→ 1枚目変更 → 2枚目変更 - 各段の左端のボタンは **「全体（完了以外）」**（v0.8.46） - 伝令ちゃん＝ランキング獲得済、1枚目＝変更完了、2枚目＝変更完了 の **3つがそろった商品は出さない**（件数からも外す） - 完了のボタン（ランキング獲得済／変更完了）を押せば出る - 伝令ちゃんを読めていない間は隠さない。タイトル末尾モードは「全体」のまま - ボタンの横位置は、項目設定の「下で区切る」の **線の番号（1〜9）** で決まる。同じ番号の線が3段で縦にそろう ### 項目（名前） - 伝令ちゃん：未登録 / 監視中 / 獲得済-登録可能 / ランキング獲得済 / SKIP - 1枚目変更：未着手 / 変更前（伝令ちゃんに登録すると自動）/ 変更中 / 変更完了 / 昔のまま放置 / SKIP / SKIP-子商品 - 2枚目変更：変更前 / 変更前-3件以上 / 変更前-上昇200% / 変更中 / 変更完了 / 昔のまま放置 / SKIP / SKIP-十分な件数 - 状態：通常 / 無視 / 無視（子商品）（左カラムで 通常・無視・無視（子商品）・全体 を切り替え） - マーク（絵文字）は基本なし。色は30セットから選べ、使われている個数も出る - 項目設定のタブ：1枚目変更 / 2枚目変更 / 🔔伝令ちゃん（名前・色・区切りを変えられる） ### 一覧の列 - 「1.2枚目変更」列：**伝令 / 1枚目 / 2枚目 / 状態** の4つのドロップダウンを縦に並べている - 伝令は手で変えられる（SKIP も可）。伝令ちゃん側の状態が変わると手動は外れて自動に戻る - 🔔伝令ちゃん列：リアルタイム順位と「開く／登録」ボタンだけ - 商品コードの下に **登録日**（Yahoo に発売日が無いので登録日にした）。並び替え可 - 商品名：入力欄＋「商品ページを開く／商品URLをコピー／✏ 詳細」 - 売上：Y-check の **前月** 分。月の合計と日別合計を比べて大きい方を使う。左カラムで金額の範囲絞り込み可 - 1枚目作成：伝令ちゃんが「獲得済-登録可能」で実際に登録済みのときだけ押せる - 2枚目作成：楽天版の作成画面を移植。ファイル名 `商品コード_商品名-mori-02.png` - 列幅：📏列幅設定、または見出しの境目をドラッグ（ダブルクリックで自動） ### 一括変更 伝令ちゃん → 1枚目変更 → 2枚目変更 → 状態（タイトル末尾では＋対応）。商品と値の両方を選んだときだけ「適用」が赤くなる。 ## 5. 知っておくこと・未解決 -
